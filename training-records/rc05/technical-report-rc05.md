RC04 正式客观分为 **17.038529 / 35**。漂移流综合性能 4.832179 / 15，最差阶段 0 / 5，恢复速度 4.206349 / 5，稳定性与抗遗忘 5 / 5，资源效率 3 / 5。三包均完成 10 轮，合计 28,208 Token。RC05 以下结果来自本地回放。

- A 冻结 RC04 训练路径。B 增加低幅度锚定候选，并检查配对轴承与寿命段。相同训练投影和父模型遇到验证寿命范围缩窄时，保留经过较广验证的父模型。C 使用训练集按工况拟合的寿命上界，同轮 RMSE 收益须超过 0.025 循环，候选同时接受寿命段和过估尾部检查。

A 十轮每轮的选中检查点和评分均与 RC04 一致。公开验证只包含来源第 2 批，整批 Macro-F1 为 0.726366，最弱观察类别为 Acetaldehyde。将该批按原始样本序分为三段用于本地诊断，window-3 的相对增益最低，为 0.00%，三段等权平均增益为 10.22%。固定检查点的历史保留率为 100%。正式报告未披露最差阶段的样本构成。

B 另做 1,679 行完整公开验证。总体 RMSE 从 RC04 的 588.95 升至 RC05 的 **656.95 分钟**。两个短轴承的 RMSE 从 285.65、418.57 降至 249.72、389.09 分钟。占 90.23% 行的长轴承 RMSE 从 610.72 升至 684.90 分钟，拉高了总体误差。

C 由独立预测入口逐样本复核。验证 RMSE 为 49.079475 循环。三包真实续训回放逐条校验了原始 PyTRiO 请求，并核对父检查点、训练步、最终产物和 64 MiB 上限。宿主评分缺失、稀疏轴承和 C 匿名 ID 均完成回退。B 已验证恢复第 5 轮后与完整运行的十轮结果一致。

## 漂移回放和留出检验

固定漂移回放使用同一阶段内官方起点 RMSE 作为分母，单轮相对增益为 1 − 当前选中模型 RMSE / 官方起点 RMSE。最差阶段取各阶段平均增益的最小值。历史保留率用旧阶段历史最优 RMSE 除以重新测量时 RMSE，最高记为 1。恢复轮次为阶段内第一次相对增益非负的轮次。

| 包 | 十轮平均增益 RC04 → RC05 | 最差阶段 RC04 → RC05 | 最低历史保留率 RC04 → RC05 |
| --- | --- | --- | --- |
| B | -9.42% → 0.94% | -37.11% → -1.89% | 100.00% → 100.00% |
| C | 9.11% → 9.27% | 5.04% → 5.01% | 98.81% → 98.99% |

B 最后一段仍未恢复到官方起点水平。独立种子 23、137、27503 的按时间推进留出中，整体、轴承等权、最差轴承和近失效 RMSE 分别比 RC04 低 11.00%、15.60%、5.09%、12.74%。训练段含完整寿命时，整轴承和整工况留出的预测保持一致。留出试验从各折仅用训练侧拟合的代理父模型开始，避免官方初始权重已经见过这些训练来源样本。漂移回放使用真正的官方起点。

C 整发动机、整数据子集和整运行工况留出中，正向误差贡献的 NASA 罚分分别降低 8.92%、60.42%、99.88%，总体 RMSE 无退化。NASA 总罚分的降幅小得多，最差单台发动机的配对 RMSE 在整工况留出中增加约 20.38%。误差取预测减真值，NASA 对过估按 expm1(误差 / 10) 计罚，对低估按 expm1(−误差 / 13) 计罚。门控继续关注过估尾部和最差阶段。筛选中未通过分组复验的全局收缩和尾部加权方案未进入提交路径。
